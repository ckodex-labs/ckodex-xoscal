xOSCAL Engine & Unified CLI

A high-assurance, developer-friendly compliance platform for NIST OSCAL (Open Security Controls Assessment Language 1.2.3). Translates codebases and infrastructure into machine-verifiable governance artifacts, multi-dimensional vector state, GitOps pull-request diffs, and air-gapped cryptographic audit packages.

60-Second Developer Quickstart

Scaffold a valid OSCAL component definition from any repository in one command without hand-writing XML or JSON:

# Build standalone binaries
make build

# Auto-detect stack, map URNs to UUIDv5, and emit OSCAL 1.2.3
./bin/xoscal-ctl init --framework nist-sp-800-53-rev5

# Evaluate multi-dimensional vector posture and evidence digests
./bin/xoscal-ctl verify --file component-definition.json

Core Capabilities

Day-0 Scaffolding

Scans Go, Python, TypeScript, Rust, Docker, and Kubernetes manifests. Deterministically synthesizes virtual URNs into RFC-4122 UUIDv5 identifiers and produces schema-valid OSCAL 1.2.3 Component Definitions.

Inspect init command

Vector State Verification

Replaces binary pass/fail theater with the formal vector product S(e,t) = <P, V, A, C, E, L, τ> (Presence, Valence, Anti-conflict, Coherence, Evidence status, Lifecycle, Temporal epoch) with tamper detection.

Inspect verify command

GitOps PR Compliance Diff

Integrates into GitHub Actions and GitLab CI to catch control drift, modifications, and posture regressions between git branches before merging, formatting Markdown summary tables for pull request comments.

Inspect diff command

GRC Spreadsheet Bridge

Provides bi-directional round-trip conversion between nested OSCAL 1.2.3 documents and flat RFC-4180 CSV tables, enabling non-technical compliance analysts to work in Excel without touching JSON.

Inspect tabular command

Rule 23 Derogation Lifecycle

Enforces the constitutional principle: Accepted risk does not rewrite history. Manages formal, time-bounded risk acceptances with hard TTL expirations, authority URNs, and compensating controls.

Inspect derogate command

Air-Gapped Audit Bundles

Exports self-contained .tar.gz archives containing canonical OSCAL models, evidence blobs with SHA-256 sidecars, cryptographic manifests, and an embedded zero-dependency WebCrypto offline viewer.

Inspect bundle-export command
