xOSCAL Engine & Unified CLI

A high-assurance, developer-friendly compliance, threat-graph, and governance platform for NIST OSCAL 1.2.3 pairing a Go gRPC/HTTP server (xoscal-server, xoscal-gateway) with the unified 24-command xoscal CLI (xoscal-ctl compatibility alias). Ships 36 sovereign and international frameworks (16,237 controls across 252 7-layer parity-verified OSCAL 1.2.3 artifacts), a formal OWL/JSON-LD v1.0.0 regulatory and threat ontology, a 20,111-node / 61,916-edge property graph with 6D Vector-State blast-radius propagation, resilient CISA KEV and MITRE ATT&CK feeds with hash-chained flight-recorder checkpoints, UTCP v1.0.1 zero-wrapper agent tools (18 native tools), an embedded Web Studio, GitOps PR diffs, Rule 23 time-bounded derogations, and air-gapped cryptographic audit bundles.

60-Second Developer Quickstart

Run diagnostics, scaffold an OSCAL 1.2.3 component definition, evaluate 6D vector posture, traverse cross-jurisdiction threat graphs, or launch the embedded Web Studio with unified xoscal commands (xoscal-ctl remains a full alias):

# Build unified CLI, compatibility alias, server, gateway, and backup binaries
make build

# Run Rule 36 deep runtime, schema, registry, UTCP, and graph diagnostics
./bin/xoscal doctor

# Auto-detect repo stack, map URNs to UUIDv5, and emit OSCAL 1.2.3
./bin/xoscal init -framework cccs-itsp-10-033

# Evaluate 6D Vector State posture S(e,t) = <P, V, A, C, E, L, tau>
./bin/xoscal verify -file component-definition.json

# Query 36-framework crosswalks, KEV blast radius, or launch Web Studio
./bin/xoscal graph crosswalk -control ac-2
./bin/xoscal graph blast-radius -target CVE-2024-3400
./bin/xoscal ui

Core Capabilities

Day-0 Repository Scaffolding

Scans Go, Python, TypeScript, Rust, Docker, and Kubernetes manifests. Deterministically synthesizes virtual URNs into RFC-4122 UUIDv5 identifiers and emits schema-valid OSCAL 1.2.3 Component Definitions.

Inspect init command

Vector State Verification

Replaces binary pass/fail theater with the formal vector product S(e,t) = <P, V, A, C, E, L, τ> (Presence, Valence, Anti-conflict, Coherence, Evidence status, Lifecycle, Temporal epoch) with tamper detection.

Inspect verify command

36-Framework Sovereign Registry & Verbatim Parity

Embeds 36 national and international baselines across 8 jurisdictions (Canada 5 incl. CCCS ITSP.10.033 2026 & PBMM, US 7, Germany 12, France 6, EU 3, UK 1, Estonia 1, International 1) with 252 7-layer artifacts and strict parity checks via verify-parity.

Inspect frameworks & verify-parity

Control Intelligence & Transition Delta

Searches and retrieves control statements, Organization-Defined Parameters (ODPs), and Canadian GC Sovereign Guidance via xoscal controls, and computes baseline migration deltas with xoscal compare cccs-itsg-33 cccs-itsp-10-033.

Inspect controls & compare

OWL/JSON-LD Ontology & Property Graph

Models 12 semantic classes and 16 predicates including Rule 17 ANTI conflict relations (OWL/JSON-LD v1.0.0) across a 20,111-node / 61,916-edge graph with 6-jurisdiction crosswalks, 6D blast-radius traversal, and Rule 34 invariant reconciliation via graph reconcile.

Inspect ontology & graph

Threat Feeds & Flight-Recorder Checkpoints

Synchronizes CISA KEV, MITRE ATT&CK, Crosswalk, and Lifecycle feeds with circuit breakers, jittered retries, offline deterministic bundles, atomic fsync checkpoints, and hash-chained verification via feeds verify-checkpoint.

Inspect feeds command

UTCP v1.0.1 Agent Tools & 5 SDK Harnesses

Exposes 18 native zero-wrapper tools across HTTP, CLI, and gRPC transports with .well-known/utcp discovery, utcp-mcp bridge generation, and typed harnesses for go-utcp, python-utcp, typescript-utcp, and rs-utcp.

Inspect utcp command

Embedded Web Studio & Deep Diagnostics

Launches a zero-dependency local explorer via xoscal serve / xoscal ui, runs Rule 36 8-domain runtime diagnostics with xoscal doctor -json, and generates bash, zsh, and fish shell completions.

Inspect serve, ui & doctor

GitOps PR Compliance Diff

Integrates into GitHub Actions and GitLab CI to catch control drift, modifications, and posture regressions between git branches before merging, formatting Markdown summary tables for pull request comments.

Inspect diff command

GRC Spreadsheet Bridge

Provides bi-directional round-trip conversion between nested OSCAL 1.2.3 documents and flat RFC-4180 CSV tables, enabling compliance analysts to review and edit controls in Excel without touching JSON.

Inspect tabular command

Rule 23 Derogation Lifecycle

Enforces the constitutional principle: Accepted risk does not rewrite history. Manages formal, time-bounded risk acceptances with hard TTL expirations, authority URNs, and compensating controls.

Inspect derogate command

Air-Gapped Audit Bundles

Exports self-contained .tar.gz archives containing canonical OSCAL models, evidence blobs with SHA-256 sidecars, cryptographic manifests, and an embedded zero-dependency WebCrypto offline viewer.

Inspect bundle-export command
