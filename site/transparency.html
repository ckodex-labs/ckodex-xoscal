SLSA L3 Provenance vs Published Assets

The SLSA L3 provenance (provenance.intoto.jsonl) covers all 14 files in the goreleaser dist/ directory — the full build context. Only 9 user-facing artifacts are published as GitHub release assets. The remaining 5 are goreleaser internal metadata files (CHANGELOG.md, artifacts.json, config.yaml, digests.txt, metadata.json) that document the build process but are not intended for download. This gap is intentional: provenance covers the build, release publishes the product.
