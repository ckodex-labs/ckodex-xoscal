API & gRPC Service Reference

The xOSCAL control plane exposes dual-transport interfaces: high-throughput binary gRPC on port 9090 and an HTTP/1.1 REST gateway on port 8080. All endpoints accept and return canonical OSCAL 1.2.3 JSON schemas with vector-state headers.

Core gRPC Services

Service Protocol Package Primary Capability Gateway Base
OscalService oscal.services.v1 Full CRUD and validation for all 8 OSCAL 1.2.3 model types /v1/catalogs, /v1/ssps, /v1/components
GovernanceService oscal.services.v1 Immutable snapshots, release attestation, and entity graph ledger /v1/entities, /v1/snapshots, /v1/releases
TransparencyExchange oscal.services.v1 Claim admission, cryptographic receipts, and SLSA provenance export /v1/claims, /v1/receipts
TransparencyGraph oscal.services.v1 Semantic lineage traversal and control inheritance graph queries /v1/graph

Common REST Gateway Endpoints

MethodHTTP PathDescription
GET/v1/componentsList all registered OSCAL Component Definitions.
POST/v1/componentsRegister a newly synthesized Component Definition.
GET/v1/catalogs/{uuid}Fetch canonical catalog by RFC-4122 UUID.
POST/v1/catalogsUpload or ingest an authoritative control catalog.
GET/v1/ssps/{uuid}Retrieve System Security Plan (SSP) with control implementations.
POST/v1/sspsStore or update System Security Plan.
POST/v1/snapshotsFreeze an immutable compliance snapshot across all models.
GET/v1/entities/{urn}Resolve an entity in the governance knowledge graph by URN.

Gateway Usage Example

Querying Component Definitions via curl:

curl -s -X GET http://127.0.0.1:8080/v1/components \
  -H "Accept: application/json"

Publishing an Assessment Plan:

curl -s -X POST http://127.0.0.1:8080/v1/assessment-plans \
  -H "Content-Type: application/json" \
  -d @assessment-plan.json
