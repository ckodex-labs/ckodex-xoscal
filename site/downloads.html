Downloads & Release Artifacts

All release artifacts are content-addressed and accompanied by cryptographic SHA-256 sidecars. Every binary is statically linked with CGO disabled and signed with Cosign in automated SLSA-compliant CI pipelines.

Quick Installation

One-line installation (Linux & macOS):

curl -fsSL https://raw.githubusercontent.com/ckodex-labs/ckodex-xoscal/main/scripts/install.sh | bash

Go toolchain installation:

go install github.com/ckodex-labs/ckodex-xoscal/server/cmd/xoscal-ctl@latest
