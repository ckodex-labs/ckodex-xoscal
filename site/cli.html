xoscal-ctl Reference Manual

The xoscal-ctl binary is the unified operator interface for machine-governed OSCAL 1.2.3 models. It is statically linked, requires zero runtime dependencies, and operates fully offline in air-gapped environments.

Command Index

Day-0 codebase scanner and deterministic UUIDv5 Component Definition synthesizer.

1. init — Repository Scaffolding

Scans application source trees (Go, Python, TypeScript, Rust, Docker, Kubernetes) and deterministically maps project characteristics to an OSCAL 1.2.3 Component Definition. All UUIDs are synthesized via RFC-4122 UUIDv5 using the DNS namespace and the canonical repo URN.

xoscal-ctl init --repo <path-to-repo> --out component-definition.json
FlagTypeDefaultDescription
--repopath.Root directory of the codebase to analyze.
--outpathstdoutOutput path for the generated OSCAL Component Definition JSON.
--typestringsoftwareComponent classification: software, service, or validation.
--namestringdirectory nameExplicit component name override.

2. verify — Vector State Verification

Evaluates artifacts against the official embedded OSCAL 1.2.3 schema and calculates the multi-dimensional trust vector S(e,t) = <P, V, A, C, E, L, τ>. Violations of mandatory security invariants dominate composite scores, strictly preventing binary false-positive theater.

xoscal-ctl verify --file <oscal-model.json> --format table
FlagTypeDefaultDescription
--filepathrequiredPath to OSCAL JSON artifact to evaluate.
--formatstringtableOutput rendering: table, json, or compact.
--fail-on-invalidbooltrueReturn non-zero exit code on schema or invariant failure.
--check-integritybooltrueVerify SHA-256 sidecars and hash references if present.

3. diff — GitOps PR Compliance Diff

Computes structural and semantic differences between two OSCAL documents (such as main vs feature-branch). In CI/CD pipelines, output is piped directly into pull request reviews to notify engineers of control regressions or dropped implementations.

xoscal-ctl diff --base baseline-ssp.json --head candidate-ssp.json --format markdown
FlagTypeDefaultDescription
--basepathrequiredBaseline OSCAL document (e.g., target branch state).
--headpathrequiredCandidate OSCAL document under review.
--formatstringmarkdownOutput format: markdown (for PR comments), json, or text.
--fail-on-regressionbooltrueExit code 1 if controls are demoted or revoked.

4. tabular — Spreadsheet Bridge

Transforms hierarchical OSCAL 1.2.3 documents into flat, standardized RFC-4180 CSV tables for compliance teams and spreadsheets, with loss-free round-trip re-import into valid OSCAL models.

# Export to CSV
xoscal-ctl tabular export --in ssp.json --out controls.csv

# Import modified CSV back into OSCAL
xoscal-ctl tabular import --in controls.csv --base ssp.json --out updated-ssp.json
SubcommandKey FlagsDescription
export--in, --outExtracts implemented requirements, control IDs, statements, and statuses.
import--in, --base, --outApplies spreadsheet updates to base document and re-validates schema.

5. derogate — Risk Acceptance Lifecycle

Constitutional Rule 23: Accepted risk does not rewrite history. Derogations attach explicit authority, justification, compensating controls, and a non-negotiable TTL. Expired derogations immediately decohere and flip posture vectors back to negative valence.

xoscal-ctl derogate create \
  --control-id "ac-2" \
  --justification "Legacy LDAP sync migration in progress" \
  --authority "urn:ckodex:authority:ciso:sec-board" \
  --ttl 720h \
  --compensating-control "Dual-operator approval on all credential changes" \
  --out derogations.json
ActionDescription
createInstantiates a cryptographically bounded derogation record with explicit TTL.
auditInspects all active derogations, flagging expired or pending renewals.
pruneRevokes expired records and preserves audit receipts in the historical trace.

6. bundle-export — Air-Gapped Bundles

Packages full compliance packages for offline auditor consumption in high-security SCIFs. Contains complete OSCAL JSON models, linked evidence files, individual SHA-256 sidecars, and an embedded zero-dependency WebCrypto HTML viewer that verifies digests locally inside an air-gapped web browser.

xoscal-ctl bundle-export --model ssp.json --evidence-dir ./evidence --out audit-bundle.tar.gz
FlagTypeDefaultDescription
--modelpathrequiredAuthoritative OSCAL document to bundle.
--evidence-dirpath./evidenceDirectory containing referenced raw evidence files.
--outpathbundle.tar.gzArchive output path.
--embed-viewerbooltrueInclude zero-dependency standalone HTML/WebCrypto verifier.
